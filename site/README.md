# Dhruv Hardin · portfolio site

## Open it on your Mac
1. Open **Terminal** and check Node: `node -v`. You want **v26** (the current LTS). If it says "command not found" or something older than v24, download the **LTS** installer from https://nodejs.org, run it, then close and reopen Terminal.
2. Go to the site folder:
   `cd ~/Downloads/DESIGN/dhruv-hardin-portfolio/site`
3. Install (first time only, takes a minute): `npm install`
4. Start it: `npm run dev`
5. Open http://localhost:3000 in your browser. To skip the intro while working: http://localhost:3000/?skip=1
6. To stop it, click the Terminal window and press Ctrl + C.

See CLAUDE.md for how everything is built.
